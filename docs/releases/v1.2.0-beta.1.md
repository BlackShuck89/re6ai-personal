# re6AI Personal 1.2.0 Beta 1 — blep.art

This is the first **blep.art-compatible beta** of re6AI Personal, following the closure announcement for e6AI. The previously released [v1.1.0 Beta 1](https://github.com/BlackShuck89/re6ai-personal/releases/tag/v1.1.0-beta.1) remains available for the original e6ai.net domain.

## What's new

- The userscript now runs on **https://blep.art/** instead of e6ai.net.
- A distinct userscript identity and namespace avoid automatically carrying old e6AI subscription identifiers into the blep.art installation.
- Updated navigation, forum links and post-history links to stay on blep.art.
- Removed hard-coded e6AI media hostnames from post thumbnails and tag/pool/comment subscription previews; media URLs are derived from blep.art page content, with on-site fallback behavior.
- Preserved the required `_client` API identifier and enforced at least 1,000 ms between requests from the userscript's internal API queue.
- Updated userscript metadata, permission declarations, repository documentation, and the inherited extension manifest.
- Added automated regression checks for domain targeting, user-agent identification, API request spacing, subscription thumbnail hosts, and release metadata.

## Validation

- GitHub Actions has passed TypeScript checks, lint, CSS compilation, userscript assembly, and port-specific checks.
- The maintainer confirmed the core features work on blep.art.
- This remains a **beta**: different user settings, browsers, accounts, and rarely used features may still have bugs.

## Installation

1. Download **`script.user.js`** from the release assets and install it using [Violentmonkey](https://violentmonkey.github.io/) or [Tampermonkey](https://www.tampermonkey.net/).
2. Confirm the userscript is called **re6AI Personal — blep.art**, version **1.2.0-beta.1**, and matches **https://blep.art/**.
3. Back up your existing settings before making changes.
4. Report problems to the [re6AI Personal issue tracker](https://github.com/BlackShuck89/re6ai-personal/issues).

This userscript is a *separate installation* from the earlier e6AI version. It does not automatically migrate numeric IDs, subscriptions, or account-specific settings from the old service. For favorites migration, use [blep.art's official importer](https://blep.art/maintenance/user/e6ai_favorite_import) rather than substituting old post IDs.

**Beta updates:** The userscript metadata points to this specific beta's release assets. Installing a later beta may require downloading it manually.
