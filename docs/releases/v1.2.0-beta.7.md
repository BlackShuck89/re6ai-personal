# reBlep Personal 1.2.0 Beta 7 — First reBlep-branded release

The enhancement userscript formerly called **re6AI Personal — blep.art** is now **reBlep Personal**. This version makes blep.art the project's permanent script identity while preserving the independent [GitHub repository](https://github.com/BlackShuck89/re6ai-personal), attribution, GPLv3 license, and older release downloads.

## Fixes since re6AI Personal 1.2.0 Beta 2

- **Search results:** Prevent infinite loading when the site's JSON API fails to respond or returns unexpected data. Restore native results and pagination on failure.
- **Post data:** Normalize blep.art's `artist`, `copyright` and `contributor` tag groups to the inherited internal model's `director` and `franchise` fields. Support wrapped and unwrapped Danbooru-style API responses.
- **Downloads:** Route the native three-dot **Download** menu through a filename-preserving download handler. The downloaded filename now respects the user-defined template. Preserve search-page download naming and sample extensions.
- **Favorites:** Respect the **Upvote on Favorite** setting, automatically upvote newly favorited posts, and avoid accidentally removing existing upvotes. Search-page favorites follow the same preference.
- **Startup:** Eliminate a blocking post-data API request during module registration, and avoid unnecessarily parsing post metadata for set-removal buttons.
- **Quality:** Add executable API-format regression fixtures and CI checks for the loader, downloads and favorites.

The maintainer confirmed that search results, dropdown filename customization, and automatic upvoting work in Firefox/Tampermonkey following the Beta 7 changes. Automated source checks and userscript build also passed.

## Installation / upgrade

Download **`script.user.js`** from the attached release assets and open it with Tampermonkey or Violentmonkey.

**Important rename notice:** The script now appears as **reBlep Personal** instead of **re6AI Personal — blep.art**.

- **Back up your existing settings** before updating or replacing the script.
- The metadata namespace remains `https://github.com/BlackShuck89/re6ai-personal/blep.art`, and the internal settings keys remain unchanged to reduce migration disruption.
- Changing a userscript's `@name` can cause the manager to recognize it as a *new* installation. If both names appear in Tampermonkey, **disable the older blep.art script** before using reBlep Personal; do not run both simultaneously. Settings might require manual export/import.
- Existing betas use version-specific update URLs and may not discover Beta 7 automatically. Manual installation is recommended.
- The script only runs on `https://blep.art/*`. Old e6AI scripts are archived and are not required.

## Beta status

This remains a **prerelease**. Browser compatibility and uncommon site operations may need additional fixes. Report reproducible bugs through [GitHub Issues](https://github.com/BlackShuck89/re6ai-personal/issues).
