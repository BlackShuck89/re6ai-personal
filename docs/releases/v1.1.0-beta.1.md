# re6AI Personal 1.1.0 Beta 1

First **independently maintained beta** of re6AI Personal for [e6ai.net](https://e6ai.net/), derived from [re6AI](https://github.com/re621/re6ai) and the [re621](https://github.com/re621/re621.Legacy) project.

**Beta / testing release.** Basic features have received an initial user smoke test, and the development CI compiles successfully, but complete cross-browser and regression testing is ongoing.

## What changed

- Independent **re6AI Personal** project branding, repository links, versioning, support links, userscript namespace, and update-check endpoint.
- The hotkey option **Go To Director** now uses e6AI terminology rather than **Go To Artist**.
- Subscription controls guard against missing/malformed tag IDs and duplicate buttons, and refresh after subscription toggles.
- Custom downloads search alternative toolbar locations if the original container is unavailable, and avoid adding duplicate controls.
- Dedicated CI checks for the build, script metadata, and beta release URLs.
- Updated documentation and explicit original-author attribution, while retaining the original GPLv3 licensing.

## Installation

Download **`script.user.js`** from the assets attached to this beta release and install using a userscript manager, such as Violentmonkey or Tampermonkey.

1. Back up your existing re6AI settings before testing.
2. Disable the original re6AI script to prevent two scripts modifying the same page.
3. Install the beta userscript, then visit e6ai.net.
4. Check subscriptions, download behavior, post pages, site preferences, and hotkeys.

This beta's `@updateURL` and `@downloadURL` deliberately **pin to this beta's release assets**, because GitHub's `releases/latest` endpoint ignores prereleases. **Future beta upgrades may require installing the next prerelease manually**. This is preferable to silently redirecting users to the wrong release. Normal automatic update feeds can be enabled for stable releases.

## Known limitations

- Compatibility has not been confirmed for every e6AI page, browser, or script manager.
- The newer re621 2.x feature set is **not** fully ported; this beta uses the existing re6AI codebase.
- Some inherited interface text may still use older re621 branding.
- The legacy browser-extension packaging has not been declared a supported product in this beta.

Please submit reproducible issues to [re6AI Personal Issues](https://github.com/BlackShuck89/re6ai-personal/issues).
