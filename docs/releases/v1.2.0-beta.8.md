# reBlep 1.2.0 Beta 8 — Repository and script rename

This is the first prerelease under the simplified **reBlep** name, following the GitHub repository rename to **[BlackShuck89/reblep](https://github.com/BlackShuck89/reblep)**.

## What changed

- **Script name:** Now **reBlep** (formerly **reBlep Personal**, and before that **re6AI Personal — blep.art**).
- **Repository:** All active project, issue-tracker, icon, release and update-check links now use `BlackShuck89/reblep`.
- **Metadata:** The generated userscript and extension manifests use the new name, and the package is named `reblep`.
- **Version:** `1.2.0-beta.8`, with installable userscript and metadata files built for this version.
- **Code:** The working Beta 7 search result, native Download menu filename, and favorite/upvote fixes are retained unchanged except for branding and URLs.

## Installation and upgrade

Download **`script.user.js`** from the release assets below and install it in Tampermonkey or Violentmonkey.

**Back up your userscript settings and subscriptions before upgrading.** Because the displayed `@name` has changed to `reBlep`, your userscript manager might install a new entry rather than replacing the old one. If both `reBlep` and `reBlep Personal` appear, disable the older blep.art script to avoid two copies running together.

The `@namespace` deliberately remains `https://github.com/BlackShuck89/re6ai-personal/blep.art` as a **stable compatibility identifier**, not as a GitHub repository or update URL. Stored settings keys also remain unchanged. All active release and update URLs point at `BlackShuck89/reblep`.

Older betas have version-pinned update URLs. They may require a manual installation to migrate to Beta 8.

## Verification

The code and packaging were checked in GitHub Actions (TypeScript, ESLint, Sass, userscript artifacts, blep.art API regression fixtures and name/update-link checks). The functional changes were browser-tested in Beta 7, and this release primarily changes identity and distribution paths.
