# re6AI Personal 1.2.0 Beta 2 — blep.art

**Hotfix release for the blep.art port.** This updates [1.2.0 Beta 1](https://github.com/BlackShuck89/re6ai-personal/releases/tag/v1.2.0-beta.1) to fix an error during initialization of the Miscellaneous module on some blep.art post pages.

## Fixed

- **Post data compatibility:** The inherited parser previously expected an e6AI-style base64 `#post-data` block with a specific internal shape. It now accepts valid plain JSON or base64 JSON when available, including compatible API-style post data.
- **Missing or incompatible metadata:** If page metadata cannot be read, the script fetches the current post from the site's JSON API, using the existing queued, rate-limited API client.
- **Unnecessary initialization:** The Miscellaneous module no longer parses post data when there are no set-removal links to enhance.
- **Startup ordering:** Post data is prepared before modules that may depend on it initialize.
- **Regression checks:** Extended automated testing covers this fallback, initial post loading, and safe behavior without set-navigation links.

The reported stack trace was:

```text
Miscellaneous/init
PostData.fromDOM
Post.getViewingPost
Miscellaneous.addRemoveFromSetButton
```

The reporter confirmed the test build resolved the error in Firefox 159 with Tampermonkey 5.5.0. GitHub Actions also passed linting, TypeScript compilation, stylesheet compilation, and userscript packaging.

## Install or upgrade

1. Download **`script.user.js`** from the release assets below and open it in [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/).
2. Update the installed **re6AI Personal — blep.art** userscript to **1.2.0-beta.2**. Avoid leaving two active copies of the blep.art script.
3. Visit a blep.art post and confirm the Miscellaneous features and any post-set controls work as expected.

**Beta update limitation:** Previous beta builds pinned `@updateURL` and `@downloadURL` to their own GitHub release tag. Users of Beta 1 may need to install this release manually.

This version is still a **beta**, not a promise of full coverage of every blep.art page or feature. Report issues at [re6AI Personal Issues](https://github.com/BlackShuck89/re6ai-personal/issues).
